# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately:

- GitHub: use [private vulnerability reporting](https://github.com/tokenbleed/nibkit/security/advisories/new)
- Telegram: [t.me/keybleed](https://t.me/keybleed)

Include a file or input that reproduces the issue. Expect a reply within a
few days.

## Scope

nibkit parses untrusted binary files. Crashes, hangs, and memory exhaustion
from malformed input are in scope; the ideal report includes the exact input.
